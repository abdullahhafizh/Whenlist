# Cloudflare Pages / Workers Builds (Git-connected)
#
# This repo is pnpm-only (`packageManager` in root package.json).
# Do NOT leave a bun.lock in the repo — Cloudflare will run
# `bun install --frozen-lockfile` and fail.
#
# ---------------------------------------------------------------------------
# Workers (API) — Git integration
# ---------------------------------------------------------------------------
# Root directory:     /  (repository root)
# Install command:    pnpm install --frozen-lockfile
# Build command:      (optional) pnpm --filter @whenlist/api build
#                     Avoid `pnpm run build` here if you only deploy the Worker —
#                     that also builds the web app.
# Deploy command:     npx wrangler deploy
#                     (root has wrangler + wrangler.toml → apps/api entry)
#   also OK:          pnpm deploy:api
#
# Put the real D1 database_id in BOTH:
#   wrangler.toml  AND  apps/api/wrangler.toml
# ---------------------------------------------------------------------------
# Pages (web UI)
# ---------------------------------------------------------------------------
# Recommended dashboard settings (root directory = repository root):
#   Framework preset: Vite (or None)
#   Build command:    pnpm --filter @whenlist/web build
#   Build output:     apps/web/dist
#   Install command:  pnpm install --frozen-lockfile
#   Node version:     22 (or set environment variable NODE_VERSION=22)
#
# If Root directory is set to `apps/web` instead:
#   Install command:  cd ../.. && pnpm install --frozen-lockfile
#   Build command:    cd ../.. && pnpm --filter @whenlist/web build
#   Build output:     dist
#
# ---------------------------------------------------------------------------
# Vercel (UI only) — Git integration
# ---------------------------------------------------------------------------
# Root Directory:     apps/web   ← MUST be web, NOT apps/api
# Install / build:    from apps/web/vercel.json (pnpm monorepo)
# Env:                VITE_API_BASE_URL=https://whenlist-api.<account>.workers.dev
#
# Do not point Vercel at apps/api — API is Cloudflare Workers + D1.
