# Zero-config Git deploys (connect repo → deploy)
#
# Cloudflare Workers (API)
#   - Connect GitHub to Workers Builds at repo root
#   - Install / Deploy defaults: pnpm + `npx wrangler deploy`
#   - Uses root wrangler.toml (Worker name "whenlist", D1 checklist-db)
#
# Vercel (web UI)
#   - Connect the SAME GitHub repo (any Root Directory: /, apps/web, or apps/api)
#   - vercel.json always builds @whenlist/web
#   - API URL defaults to production Worker if VITE_API_BASE_URL unset
#
# Local web still uses http://127.0.0.1:8787 unless apps/web/.env overrides.
